# 学习速查与建议顺序

先读 u33–u34 的化学与证据区别，再读 u16–u22 的氨解动力学/传质；接着 u23–u25 的气固与优化；然后比较 u01–u04、u13–u15、u26–u32 的双腈路线；最后 u05–u12 的重排、聚合物与环境经济评价。此顺序是本学习页建议，不声称原论文的统一流程。

| 路线 | 代表结果与口径 | 主要限制 |
|---|---|---|
| Pd水转移两段 | 真实PET→TPN约39–51%；模型酰胺最高68% | 单腈平衡、清洗兼容、Pd回收损失 |
| ZnCl₂→TiO₂→Pd/C | TP85.3%、TPN73.1%分析/65%分离、PXDA87.4%；作者总54.5% | 220/260℃，焦化与多步口径 |
| 无水NH₃气固 | 120℃2h TP90.6mol%、96.2%纯度 | 延时碳化，RSM预测纯度超上限 |
| 尿素/γ-Al₂O₃热解 | 550℃TPN32.53C%、腈内选择性85% | C%不等于摩尔收率；高温裂解 |
| 磷改性/氨气热解 | 500℃TPN52.27C%分析、32.13C%分离 | CO₂未测、14.67%未识别碳与回收损失 |
| 热—电Hofmann | PABA/PPD总72.2%、FE43.4% | 活性溴回还原、Cr(VI)与内部计量疑点 |
| 聚合物LCA | 15.22kgCO₂eq/kg，基线比原生GWP低15% | 同质量与放大假设；非纤维性能验证 |

详细条件及精确出处见对应单元，不把这些数字直接排名。

五个始终要问的问题：原料是否相同？目标结构是否相同？分母和分析/分离口径是否相同？数据是实测、预测还是理论值？环境经济比较边界包含什么？
